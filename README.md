# RunBeat 🏃‍♀️

초보 러너가 직접 쓰려고 만든 안드로이드 러닝 앱.
인터벌 코스를 직접 짜고, 케이던스 메트로놈에 발을 맞추며, 음악을 들으면서 달릴 수 있다.

> 개발 과정과 해결한 문제는 아래 [개발 기록](#개발-기록)에 단계별로 정리했다.

## 기능
- 운동 기록: 시간, 거리, 현재/평균 페이스, 칼로리, 케이던스, 걸음 수
- 지도 경로 (OpenStreetMap, API 키 필요 없음)
- 1km 구간 기록표 + 구간 페이스 차트
- 1km마다 음성 안내: "3킬로미터. 페이스 6분 10초. 경과 시간 18분 40초."
- 케이던스 메트로놈 (160/170/180, ±1/±5 조절, 러닝 중에도 변경 가능)
- 음악 앱과 함께 사용: 메트로놈은 음악 위에 섞이고, 음성 안내 때는 음악 소리가 잠깐 줄어듦
- 기록 삭제: 기록 목록의 휴지통 버튼, 카드 길게 누르기, 상세 화면 맨 아래 "이 기록 삭제"
- 두 가지 모드: **자유 달리기**(기록만) / **코스 달리기**(인터벌 타이머)
- 코스: 기본 코스 4개(입문·초보·심화·30분 지속 RUN) + 내 코스 만들기/복사/수정/삭제
  - 구간 종류: 워밍업 걷기 · 달리기 · 걷기 · 쿨다운 걷기, 반복 블록(× N)
  - 구간이 바뀔 때, 10초 전, 절반 지점에서 음성 안내
  - 메트로놈은 코스의 달리기 구간에서만 울림
- 자동 일시정지: 6초 이상 멈추면 기록·인터벌 타이머가 함께 멈추고, 다시 달리면 자동 재개 (설정에서 끄기 가능 — 대회 땐 끄기 추천)
- 잠금화면/알림창 버튼: 달리는 중 [일시정지][건너뛰기], 멈춘 중 [재개][종료]

## APK 만드는 법
1. Android Studio 설치 (https://developer.android.com/studio)
2. `File > Open` → 이 `RunBeat` 폴더 선택 → Gradle 동기화가 끝날 때까지 대기
   (처음엔 다운로드 때문에 몇 분 걸려요. 업그레이드 안내가 뜨면 일단 닫아도 돼요)
3. `Build > Generate App Bundles or APKs > Generate APKs`
4. 완료 알림의 `locate` 클릭 → `app/build/outputs/apk/debug/app-debug.apk`

## 폰에 설치
- **방법 A (추천)**: 폰 설정 > 휴대전화 정보 > 소프트웨어 정보 > 빌드번호 7번 탭 → 개발자 옵션 > USB 디버깅 켜기 → USB 연결 → Android Studio의 ▶ Run 버튼
- **방법 B**: app-debug.apk를 카톡 '나에게 보내기'나 구글 드라이브로 폰에 옮겨서 열기 → "출처를 알 수 없는 앱 설치" 허용

## 코드 구조

|---|---|
| `RunService` | 핵심. GPS·걸음센서·1초 타이머·구간 계산·저장 (Foreground Service) |

| `AutoPauseDetector` | 자동 일시정지 판단 (GPS 속도 + 걸음 센서) |
| `Course` / `CourseStore` | 코스 데이터·기본 코스 / 내 코스 저장 |
| `CourseListActivity` / `CourseEditActivity` | 코스 고르기 / 코스 편집 |
| `RunState` | 서비스 ↔ 화면 사이 공용 상태 |
| `MainActivity` | 메인 화면 |
| `HistoryActivity` / `RunDetailActivity` | 기록 목록(삭제) / 상세(지도·차트·구간표·삭제) |
| `PaceChartView` | 구간 페이스 막대 차트 (Canvas로 직접 그림) |
| `RunRecord` / `RunStorage` | 기록 데이터 / JSON 파일 저장 |

## 개발 기록

> 처음 버전은 커밋 하나로 올라가 있어서, 그 전까지의 개선 과정을 단계별로 남긴다.
> 각 단계는 **무엇을 했는지 → 어떤 문제가 있었는지 → 원인 → 해결** 순서로 적었다.

### v0.1 — 최소 기능 버전 (2026.10.03)
일주일 뒤 마라톤 대회에서 직접 쓰는 것을 목표로, 꼭 필요한 기능만 먼저 만들었다.

- **기록**: 시간, 거리, 현재/평균 페이스, 칼로리, 케이던스, 지도 경로, 1km 구간표와 구간 페이스 차트
- **설계 결정**
  - 화면이 꺼지고 주머니에 넣어도 기록이 멈추지 않도록 GPS·타이머를 **Foreground Service**에 둠
  - 메트로놈은 **오디오 포커스를 요청하지 않고** 재생 → 유튜브뮤직 같은 음악 앱이 멈추지 않고 소리가 섞임
  - 음성 안내는 말하는 동안만 `AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK`으로 음악 볼륨을 잠깐 줄임 (런데이·삼성헬스와 같은 방식)
  - 메트로놈 박자가 밀리지 않도록 `sleep()` 반복 대신 **"다음에 울릴 절대 시각"** 기준으로 대기 (오차 누적 방지)
  - GPS 튐 걸러내기: 정확도 25m 초과 / 3m 미만 이동 / 사람이 낼 수 없는 속도의 점은 버림
  - 1km 도달 시각은 두 GPS 점 사이를 **선형 보간**해서 계산 (GPS가 1초 간격이라 생기는 오차를 줄임)
  - 서버 없이 기기 내부에 JSON 파일로 저장, 30초마다 중간 저장 (앱이 강제 종료돼도 기록 보존)
- 칼로리는 `체중 × 거리(km) × 약 1.0` 경험식 사용 (달리기의 km당 소모 칼로리는 속도와 거의 무관)
- 케이던스는 가속도 센서 원본 대신 **걸음 감지 센서(`TYPE_STEP_DETECTOR`)**를 사용 → 제조사 알고리즘이라 정확하고 배터리 소모가 적음. 최근 15초 걸음을 큐(슬라이딩 윈도우)로 세서 계산

### v0.2 — 짧은 기록이 저장되지 않는 버그 (2026.10.04)
- **문제**: 시작 후 5초 만에 종료한 기록이 목록에 나타나지 않음
- **원인 1**: 종료 시 GPS 해제 → 센서 해제 → 메트로놈 정지 → **저장** 순서라서, 앞 단계에서 예외가 나면 저장까지 도달하지 못하는 구조
- **원인 2**: 기록 목록 화면이 기록 0개일 때 화면 자체를 "기록 없음" 화면으로 **갈아끼워서**, 이후 기록이 생겨도 목록이 다시 보이지 않음
- **해결**: 저장을 **가장 먼저** 하고 정리 작업은 각각 `try-catch`로 분리 / 목록과 안내 문구를 겹쳐 두고 보이기·숨기기만 전환 / 저장 완료 토스트 추가

### v0.3 — 디자인 개편 + 기록 삭제 (2026.10.04)
- 어두운 배경 + 둥근 카드 레이아웃, 선택된 bpm이 주황색으로 표시되는 칩 버튼
- GPS 상태를 점 색깔로 표시 (초록 양호 / 노랑 약함)

- 목록 상단에 총 횟수·총 거리, 상세 화면에 최고 1km 페이스

### v0.4 — 인터벌 코스 + 자동 일시정지 + 잠금화면 컨트롤 (2026.10.04)
v0.1은 "기록 앱"일 뿐 원래 목표였던 **인터벌 타이머**가 아니었다. 코드를 짜기 전에 사용자 흐름부터 설계했다.

- **흐름**: 홈에서 `자유 달리기` / `코스 달리기` 선택 → 코스 고르기 → (필요하면) 코스 편집 → 달리기
- **코스 구조**: 워밍업 걷기 · 달리기 · 걷기 · 쿨다운 걷기 + **반복 블록(× N)**
  - 반복 블록이 없으면 "1분 달리기 + 2분 걷기 × 6"을 12줄로 직접 쌓아야 해서 추가
  - 기본 코스 4종: 입문 / 초보 / 심화 / 30분 지속 RUN (처음엔 "입문 1주차, 4주차"였는데 중간 주차가 비어 어색해서 이름 변경)
- **"운동 시간" 개념 도입**: 실제 시간에서 일시정지 시간을 뺀 시간. 기록·페이스·인터벌 타이머가 모두 이 값을 쓰므로, 일시정지하면 **인터벌 타이머도 자동으로 함께 멈춤**
- **인터벌 엔진을 안드로이드와 분리(`IntervalEngine`)**: 순수 자바 클래스라 기기 없이 시뮬레이션 테스트 가능
  - 테스트 중 "6분 40초 시점은 달리기 1/6"이라는 **테스트 쪽의 계산 실수**를 엔진이 잡아냄 (워밍업 5분 + 달리기 1분 = 6분이므로 실제로는 걷기 구간이 맞음) → 테스트를 고침
- **자동 일시정지(`AutoPauseDetector`)**: GPS 속도 + 걸음 센서를 함께 사용
  - 시속 약 2km 미만 + 걸음 없음이 **6초** 계속되면 일시정지 (걷기 속도 시속 4~5km와 충분히 구분됨)
  - 빠른 위치가 **2번 연속**이거나 걸음이 감지되면 재개 (GPS 튐 한 번으로 재개되지 않게)
  - 출발 30m 이내에는 판단하지 않음 (출발선에서 GPS 기다리며 서 있는 경우)
  - 대회에서는 급수대 정지 시간도 공식 기록에 포함되므로 **끌 수 있는 스위치**로 만듦
- **음성 안내**: 구간 전환, 10초 전, 절반 지점 / 메트로놈은 코스의 **달리기 구간에서만** 울림
- **잠금화면 알림 버튼**: 달리는 중 [일시정지][건너뛰기], 멈춘 중 [재개][종료] (실수 방지를 위해 종료는 멈춘 상태에서만)

### v0.5 — 갤럭시 실기기 테스트 피드백 (2026.10.04)
실제 갤럭시 폰에 설치해서 써보며 발견한 문제들.

- **문제 1**: 홈 화면 맨 아래 버튼이 **갤럭시 내비게이션 바에 가려짐**
- **문제 2**: 코스 고르기 화면에서 **제목 줄이 첫 번째 코스("입문 RUN")를 덮음**
- **원인**: `targetSdk 35`(Android 15)부터 앱 화면이 상태바·내비게이션 바 **뒤까지 강제로 확장(edge-to-edge)**되는데, 그 영역을 비워두는 처리가 없었음
- **해결**: 모든 화면의 부모 클래스 `BaseActivity`를 만들어, 시스템이 알려주는 바 높이(`WindowInsets`)만큼 안쪽 여백을 줌 → **두 바 사이 공간만 앱 화면**이 됨. 키보드 높이도 같이 처리. 기본 액션바 대신 직접 만든 헤더를 내용 위에 쌓아서 덮지 않게 함
- **추가 점검**: 갤럭시의 **큰 글자 설정**에서 76sp 타이머가 화면을 넘칠 수 있음 → 큰 숫자는 칸 너비에 맞춰 자동 축소(`autoSizeTextType`), 버튼·이름은 한 줄 + 말줄임
- **코스 목록 UX 개선**: 기본 코스는 [복사] 버튼만, 커스텀 코스는 [⋯] 메뉴(수정·복사·삭제). 복사하면 파일 복사처럼 `커스텀 코스` → `커스텀 코스(1)` → `커스텀 코스(2)` 이름 자동 생성 (사용자가 바꾸는 이름은 중복 허용)
